What each form is saying

Three different spatial metaphors, so the cards no longer compete for the same shape.

Pin on a chart

Geomap

A graticule, a coastline, a dashed track and a live marker. Geographic position is the subject, so the card reads as a map surface rather than a status chip wearing one.

Values on a plan

Image map

A floor plan with rooms and door gaps, and a reading pinned inside each zone. The numbers are annotations on an image — which is what an image map is — instead of a row of unrelated stats.

Links between nodes

Status map

A hub with satellites, each link coloured by connection health. Connection status is about topology and link state, so that is what the card draws.
